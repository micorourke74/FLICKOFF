# Third-party notices

No third-party runtime code or art is shipped by the foundation branch.

Unity editor packages are resolved through the project manifest and Unity package registry. Their licenses remain governed by Unity's package notices.

The public GTALPR repository is used as a source-reference snapshot only. It is not vendored into this repository and has no shipping runtime dependency. Its provenance is recorded in `ASSET_PROVENANCE.md` and `docs/reference/`.
